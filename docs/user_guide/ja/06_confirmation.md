# 計画の確定と再計画

「このツールの狙い・目的」で紹介したとおり、このツールは
**計画を作る → 合意する → 進める → 振り返って見直す** というサイクルで使うことを想定しています。
この章では、そのための機能（確定・変更案・全面再計画）を説明します。

確定の機能は、使わなくても構いません。
確定しない間は、条件を変えるたびに日程が自由に組み直されます。
関係者と合意した計画を、あとで勝手に変わらないように残しておきたくなったら、この章の機能を使います。

## 3つの状態

計画は、いつも次の3つの状態のどれかにあります。
いまの状態は、画面上部の**状態帯**の色と文字で分かります。

| 状態 | 状態帯 | ガントチャートに映るもの |
| --- | --- | --- |
| 未確定 | 灰色「未確定」 | 入力から毎回組み立てた日程。条件を変えるとすぐに組み直されます |
| 確定済み | 緑「確定済み」 | 合意して保存した日程 |
| 変更案 | 橙「変更案」 | 確定した日程に、確定後の変更を当てはめた日程（まだ合意していない案） |

状態帯はどのタブにも表示されます。
確定や変更の操作ボタンは、**ガントチャートタブを開いているときだけ**状態帯に表示されます。

## 計画を確定する

関係者と計画について合意できたら、その日程を確定します。

1. 「ガントチャート」タブを開きます。
2. 状態帯の「確定する」を押します。

状態帯が緑になり、確定した日付が表示されます。

## 確定した後に計画を変える（変更案）

確定した後も、これまでどおり自由に入力を変えられます。
ただし、日程に関わる変更をすると、それは**変更案**として扱われ、状態帯が橙になります。
変更案は、あなたが「変更を確定」するまで、確定した日程を書き換えません。

変更案になる操作には、次のようなものがあります。どのタブで変えても同じです。

- タスクの日数・チーム・有効／無効・開始固定日を変える（ガントチャートでバーを動かす場合も含みます）
- ジョブを追加する、ワークフローを変える
- ライン数や休業日を変える

一方、タスクの**状態**（未着手・進行中・完了）を記録しても、変更案にはなりません。状態を変えても、バーはその場から動きません。

### 変更案を確定する・やめる

変更案のときは、状態帯に次のボタンが表示されます。

| ボタン | 内容 |
| --- | --- |
| 変更を確定 | 変更案の日程を、新しい確定の日程にします |
| 選択した変更を確定 | ガントチャートで選んだタスクの変更だけを確定します。その変更の影響で動いた後ろのタスク（押し下げたほかのジョブのタスクも含みます）も一緒に確定します。選ばなかった変更は変更案に残ります |
| 変更を破棄 | 変更案をやめて、最後に確定した時点の計画に戻します（「選択した変更を確定」で確定した分は残ります）。確定の後に記録したタスクの状態（進行中・完了）と実績は、そのまま残ります。状態も戻したいときは、確認のメッセージで「進行中・完了にした状態と実績も、確定した時点に戻す」にチェックを付けます |
| 全面再計画 | 計画全体を組み直します（下記） |
| 未確定に戻す | 確定をやめます（下記） |

「変更を破棄」と「未確定に戻す」は、実行する前に確認のメッセージが出ます。どの操作も Ctrl+Z で元に戻せます。

変更案のあいだは、プロジェクト分析タブも変更案の日程を集計します。
「ガントチャートを生成」でファイルに書き出すときは、変更案と確定した日程のどちらを書き出すかを選べます。

## 進み具合を反映する

計画を進め始めたら、定例のミーティングなどで、各タスクの状態（未着手・進行中・完了）を記録します。
状態は、ジョブ作成タブのタスク上書き、またはガントチャートの編集ウィンドウや右クリックで変えられます。
状態を記録しても、バーはその場から動きません。進行中・完了にした時点の日程が、そのタスクの**実績**として記録されます。
確定していない計画や、確定の後に追加したタスクでも記録されます。

- **進行中**のタスクは、実績の開始日から始まります。遅れているときは日数を延ばせます（後ろのタスクも合わせて動きます）。
- **完了**のタスクは、実績の開始日から終了日のまま置かれます。休業日を後から追加しても、ワークフローの日数を後から直しても伸び縮みしません。
- 進行中・完了のタスクは、ガントチャートのドラッグでは動かせません（うっかり実績を動かさないためです）。
- 進行中・完了のタスクでは、日程に効かない項目は入力できません（進行中は開始固定日、完了は開始固定日・日数・チーム）。

実際の日付が予定とずれたときは、ガントチャートの編集ウィンドウで**実績の開始日**（完了なら**実績の終了日**も）を直します。
休業日に作業した場合も、その日付のまま記録できます。
確定済みの計画では、実績が確定した日程と違うタスクは変更案になるので、後ろのタスクへの影響を確かめてから「変更を確定」します。

状態を未着手に戻すと、実績は消え、計画の値（日数・開始固定日など）で置き直されます。

## 全面再計画

変更案では、変更したタスクとその後ろのタスクだけを置き直し、**ほかの確定済みのタスクはできるだけ動かしません**。
変更したタスクが延びたり後ろへ動いたりして、同じチームで後ろに控えているタスクと重なるときは、その後ろのタスクを重なる分だけ**押し下げます**（押し下げたタスクの後ろのタスクも一緒にずれます）。
どのタスクも、確定した日より前には動きません。
開始固定日を設定したタスク、ドラッグで動かしたタスク、進行中・完了のタスクは押し下げません。その手前に入りきらないタスクは、その後ろへ回ります。

変更案は確定した日程をなるべく保ったまま変更を当てはめるので、次のようなときは**全面再計画**で計画全体を組み直すと、よりよい計画になります。

- タスクが早く終わった、日数を減らした、ライン数を増やしたなどで、空きができたとき（変更案では、タスクを確定した日より前へは動かしません）
- 変更が重なって、押し下げられたタスクが増えたとき

変更案で動いたタスクが全体の一定の割合（オプションで設定。既定は20%）を超えると、状態帯に全面再計画を勧める表示が出ます。

### 全面再計画のしかた

1. ガントチャートタブで、状態帯の「全面再計画」を押します。
2. 「新しい計画が始まる日（基準日）」を選びます。初めは今日の日付が入っています。
3. 「全面再計画」を押します。

<figure>
<img src="images/plan_replan_dialog.png" alt="全面再計画の画面" style="max-width:120mm">
<figcaption>全面再計画の画面</figcaption>
</figure>

全面再計画では、次のように組み直します。

- **未着手のタスク**を、基準日以降に全体として組み直します。
- **進行中・完了のタスク**は動かしません。
- 基準日を今日より後にした場合、今日から基準日の前日までに始まる予定の未着手タスクは、今の確定のまま残します（予定どおり着手する前提です）。
- 基準日に今日より前の日付を選ぶと、警告が表示されます。

組み直した結果は、すぐには確定されず、**変更案として表示されます**。
状態帯の先頭に「全面再計画（基準日 から）」と表示されます。

<figure>
<img src="images/plan_replanned.png" alt="全面再計画の後の画面">
<figcaption>全面再計画の後。未着手のタスクを、基準日（11/02）以降に全体として組み直しました</figcaption>
</figure>

結果を確かめて、よければ「変更を確定」で新しい計画として確定します。
やめる場合は「変更を破棄」を押すと、全面再計画の前の確定に戻ります。
全面再計画を確定した後は、状態帯に「11/02 から新計画（11/02 再計画）」のように、基準日と実行した日が表示されます。

## 未確定に戻す

確定をやめて、確定する前と同じように自由に日程を組み直せる状態に戻します。
プロジェクト全体が対象です。

| 消えるもの | 残るもの |
| --- | --- |
| 確定日程、変更案（ドラッグで動かした位置を含む） | 進行中・完了のタスクの実績（実際に進めた事実なので、実績の日程のまま置かれます）、ジョブ・タスクの設定、開始固定日 |
