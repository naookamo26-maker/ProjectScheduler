# 起動と初期設定

## 起動する

`ProjectSchedulerGUI.exe` をダブルクリックすると起動します。
インストールは不要で、この1ファイルだけで動きます。

起動した直後は、プロジェクトがまだ開かれていません。
タブは灰色で操作できず、画面の下に「プロジェクトファイルを新規作成するか、開いてください」と表示されます。

## プロジェクトファイルの扱い

計画は、1つのプロジェクトごとに1つのファイル（拡張子 `.pschedule`）に保存します。
ファイルの操作は、すべて「ファイル」メニューから行います。

| 操作 | メニュー | ショートカット |
| --- | --- | --- |
| 新しく作る | ファイル → 新規プロジェクト | |
| 開く | ファイル → プロジェクトを開く | |
| 上書き保存する | ファイル → 保存 | Ctrl+S |
| 別の名前で保存する | ファイル → 名前を付けて保存 | Ctrl+Shift+S |

- `.pschedule` ファイルを画面にドラッグ＆ドロップして開くこともできます。
- 新しく作ったプロジェクトは、最初に保存するときに保存先とファイル名を選びます。

### 保存は自分で行います

画面で入力した内容は、**保存するまでファイルには書き込まれません。**
まだ保存していない変更があると、ウィンドウのタイトルのファイル名の前に `*` が付きます。
保存すると `*` が消えます。

保存しないまま別のファイルを開いたり、ツールを終了したりしようとすると、確認のメッセージが出ます。

### 操作は元に戻せます

入力や削除の操作は、「編集」メニューの「元に戻す」（Ctrl+Z）で取り消せます。
取り消した操作は「やり直す」（Ctrl+Y）で戻せます。
操作したときに開いていたタブや選んでいた行も、一緒に元に戻ります。

いろいろな条件を試してから元に戻せるので、気軽に計画を変えてみてください。

## オプション設定

「編集」メニューの「オプション」で、ツールの動きを設定できます。
ここでの設定はこのパソコンに保存され、プロジェクトファイルには含まれません。

<figure>
<img src="images/options_dialog.png" alt="オプション設定の画面" style="max-width:95mm">
<figcaption>オプション設定</figcaption>
</figure>

| 項目 | 内容 | 既定 |
| --- | --- | --- |
| 表示言語 | 日本語・English・Tiếng Việt・简体中文から選びます。**ツールを起動し直すと切り替わります** | パソコンの言語 |
| Undoに使うメモリの上限 | 元に戻せる操作の履歴に使うメモリの量です。通常は変える必要はありません | 128 MB |
| バーをドラッグするときに押すキー | ガントチャートでタスクの日程をドラッグで動かすときに押しておくキーです（「ガントチャート」の節で説明します） | Shift |
| 編集で動いたバーを強調する時間 | ガントチャートで日程を動かしたとき、影響を受けたタスクを目立たせておく時間です | 次の操作まで |
| 全面再計画を案内する影響範囲 | 確定した計画を変更するときに、どのくらい多くのタスクが動いたら計画全体の組み直しを勧めるかの目安です（「計画の確定と再計画」の章で説明します） | 20% |

「既定値に戻す」を押すと、画面上の値が既定に戻ります。どの場合も「OK」を押すまで保存されません。
