# このツールの狙い・目的

プロジェクトスケジューラーは、**チームが同時にこなせる作業量と締切を踏まえて、
無理なく進められる期間の計画を組み立て、関係者と合意しながら進めていく**ためのツールです。

作業の流れと、それを受け持つチームを登録すると、ツールが日程を自動で組み立てます。
できあがった計画はガントチャートで確かめられ、条件を変えて何度でも試せます。

!!! kikan "大切な前提 ― これは「期間」の計画です"
    このツールで扱う日数は、すべて**期間**です。**工数（人日）ではありません。**

    - 各タスクの「日数」は、**着手してから完了するまでにかかる期間**です。
      その作業にどれだけの手間がかかるか（工数。人日などで数える作業量）は表しません。
      「10日のタスク」は「着手から10営業日で仕上がる」という意味であり、
      「10人日の作業量」という意味ではありません。
    - チームの「ライン数」は、そのチームが**同時に並行して進められる作業の本数**です。
      人数そのものではありません。
    - このツールは工数を集計・管理しません。コストや人員の見積もりが必要な場合は、
      別の手段と組み合わせてお使いください。

    この前提は、この先の説明でも繰り返し出てきます。日数やライン数を入力するときは、
    「どれくらいの期間で仕上がるか」「同時にいくつ進められるか」を考えてください。

## どんな困りごとを解決するか

| よくある困りごと | このツールでは |
| --- | --- |
| 表計算ソフトの計画表では、入力ミスや参照ミスが起きやすい | 名前を選び、線でつなぐだけで計画を組み立てられます |
| 作業のつながり（何が終わると何を始められるか）の全体像が見えない | 作業の流れを図で見ながら作れます |
| つながりは正しくても、チームの手が回らない日程になってしまう | 同時に進められる本数と休日を踏まえて、日程を自動で組みます |
| 作業がぶつかったとき、どれを先に進めるかで揉める | 優先度に従い、一貫したルールで順番が決まります |
| 締切に間に合うかどうかが見えない | 間に合わない作業と、その遅れの日数が一目で分かります |
| 同じ流れの仕事を何件も手で並べるのは大変 | 作業の流れを「型」として作り、必要な数だけ展開できます |
| 合意したはずの計画が、いつの間にか変わっている | 合意した計画を「確定」として残せます。変更は試してから、明示的に確定します |

1. **計画を作る** ― 期間・作業の流れ・仕事を登録し、条件を変えながら日程を試します。
2. **合意する** ― 関係者と合意できたら、その計画を「確定」します。
   確定した計画は、あとで勝手に変わることはありません。
3. **進める** ― 定例のミーティングなどで、各タスクの状態（未着手・進行中・完了）を反映します。
4. **振り返る** ― マイルストーンや月ごとに見直し、必要なら計画を変更して、もう一度合意します。

## 利用規模と用途

数件の作業からなる小さな計画から、数千件の作業を抱える大きなプロジェクトまで、
同じ考え方で扱えます。

- 「チーム」は、部署でも、個人でも、協力会社でも構いません。
  ご自分の進め方に合わせて自由に割り当ててください。
- 1つのプロジェクトに限らず、複数の業務をまとめて1つの計画として扱うこともできます。
- 大まかな見通しを立てる使い方も、タスクを細かく区切り、その状態で進み具合を追う使い方もできます。
  具体的な例は「活用例」の章で紹介します。

## このツールが扱わないもの

このツールは、**期間の計画を立て、合意し、見直していく**ことに絞っています。
次のことは扱いません。必要な場合は、別の手段と組み合わせてお使いください。

| 扱わないもの | このツールでの考え方 |
| --- | --- |
| 人員配置 | 仕事はチームに割り当てます。チームの中で誰が担当するかは決めません |
| 詳細なタスク管理 | タスクは日程を組むための単位です。作業の中身や細かな手順、担当者ごとのやることリストは管理しません |
| 作業工数の予実管理 | 日数は期間であり、工数ではありません。作業にかかった工数の記録や、見積もりとの比較はしません |
| 詳細な進捗管理 | 進み具合は、タスクの状態（未着手・進行中・完了）で反映します。何％まで進んだかといった細かな進捗は追いません |
| 時間単位の予定 | 日程は日単位で組みます。時刻や時間単位の予定は扱いません |
| コスト・予算の管理 | 費用の見積もりや集計はしません |
