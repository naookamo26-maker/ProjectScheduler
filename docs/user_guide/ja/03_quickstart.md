# クイックスタート

この章では、小さな計画を一から作りながら、ツールの使い方をつかみます（20分ほど）。

ゲームのアップデートで、3つのコンテンツ（新キャラクター・新ステージ・新アイテム）を作る計画を立てます。
どのコンテンツも「仕様作成 → アート制作 → 確認」の順に進めます。

| | 内容 |
| --- | --- |
| 開発開始日 | 2026-10-05 |
| 締切 | 配信（2026-11-13） |
| チーム | プランナー（同時に1本）、アート（同時に2本） |
| 作業の流れ | 仕様作成（プランナー・3日）→ アート制作（アート・5日）→ 確認（プランナー・2日） |
| 仕事 | 新キャラクター（優先度1）、新ステージ（優先度2）、新アイテム（優先度3） |

まず「ファイル」→「新規プロジェクト」を選びます。空のプロジェクトが開きます。

## 手順1: 基本情報を入れる

「基本情報設定」タブで、次のように入力します。

1. **プロジェクト概要**: プロジェクト名に「はじめてのアップデート」と入力し、開発開始日に 2026-10-05 を選びます。
2. **マイルストーン**: 「＋追加」を押し、追加された行の名前を「配信」に、締切日を 2026-11-13 にします。
3. **チーム**: 「＋チーム」を押し、追加されたチームの名前を「プランナー」にします。
   チーム名の下の行（開発開始日の行）の「ライン数」を 1 にします。
4. 同じように「アート」チームを追加し、ライン数を 2 にします。

<figure>
<img src="images/tutorial_1_basic_info.png" alt="手順1を終えた基本情報設定タブ">
<figcaption>手順1を終えたところ</figcaption>
</figure>

プランナーのライン数を 1 にしたので、プランナーは同時に1つの作業しか進められません。
この設定が日程にどう効くかは、手順4で確かめます。

## 手順2: 作業の流れ（ワークフロー）を作る

「ワークフロー設計」タブで、作業の流れの型を作ります。

1. 左上の「＋追加」を押し、ワークフロー名に「追加コンテンツ制作」と入力します。
2. 右側の広い領域（ノードビュー）の何もないところを右クリックし、「タスクを追加」を選びます。
3. タスク名「仕様作成」、担当チーム「プランナー」、所要日数「3」を入力して「OK」を押します。
4. 同じように「アート制作」（アート・5日）を追加します。このとき「先行タスク」で「仕様作成」を選びます。
5. 同じように「確認」（プランナー・2日）を追加し、先行タスクに「アート制作」を選びます。

<figure>
<img src="images/tutorial_2_task_dialog.png" alt="タスクを追加する画面" style="max-width:120mm">
<figcaption>「アート制作」を追加しているところ。先行タスクに「仕様作成」を選んでいます</figcaption>
</figure>

!!! kikan-note "所要日数は「期間」です"
    所要日数には、そのタスクが**着手してから仕上がるまでの期間**を入れます。
    何人で取り組むか（工数）ではありません。

<figure>
<img src="images/tutorial_2_workflow.png" alt="手順2を終えたワークフロー設計タブ">
<figcaption>手順2を終えたところ。3つのタスクが矢印でつながっています</figcaption>
</figure>

先行タスクは、ノードの右端の丸から次のノードへドラッグしてつなぐこともできます。

## 手順3: 実際の仕事（ジョブ）を作る

「ジョブ作成」タブで、型から実際の仕事を作ります。

1. 「＋追加」を押します。「新しいジョブ」という行が追加されます。
2. ジョブ名を「新キャラクター」に、既定マイルストーンを「配信」に、優先度を「1」にします。
   ワークフローには、手順2で作った「追加コンテンツ制作」が選ばれています。
3. 同じように「新ステージ」（優先度2）と「新アイテム」（優先度3）を追加します。

<figure>
<img src="images/tutorial_3_jobs.png" alt="手順3を終えたジョブ作成タブ">
<figcaption>手順3を終えたところ</figcaption>
</figure>

これで、3つのジョブがそれぞれ「仕様作成 → アート制作 → 確認」のタスクを持ちました。

## 手順4: ガントチャートで日程を見る

「ガントチャート」タブを開きます。
右上の「配置コントロール」のつまみを左端の「最速」まで動かします（数値が 0% になります）。
これで、各タスクができるだけ早く始まる日程が表示されます
（配置コントロールについては「日程の決まり方」の章で説明します）。

<figure>
<img src="images/tutorial_4_gantt.png" alt="手順4のガントチャート">
<figcaption>プランナーのライン数が 1 のときの日程</figcaption>
</figure>

3件の「仕様作成」が同時には始まらず、**優先度の順に1件ずつ**進んでいることに注目してください。
プランナーのライン数が 1 なので、同時に1つしか進められないからです。
「確認」もプランナーの作業なので、ほかの仕様作成と重ならないように置かれています。

## 手順5: 条件を変えてみる

「基本情報設定」タブに戻り、プランナーのライン数を 2 に変えます。
もう一度「ガントチャート」タブを開くと、日程が組み直されています。

<figure>
<img src="images/tutorial_5_gantt.png" alt="手順5のガントチャート">
<figcaption>プランナーのライン数を 2 にしたときの日程</figcaption>
</figure>

新キャラクターと新ステージの仕様作成が同時に始まり、全体の完了が早まりました。
このように、**条件を変えて日程の変化を確かめる**のが、このツールの基本的な使い方です。

!!! lines-note "ライン数を増やすことは、人を2倍にすることではありません"
    ライン数 2 は「同時に2つの作業を進められる」という意味です。
    実際にそれができるか（人を増やす、担当を分けるなど）は、チームの実情に合わせて判断してください。

変更を取り消したいときは、Ctrl+Z で元に戻せます。

## 手順6: 保存する

「ファイル」→「保存」（Ctrl+S）を選び、保存先とファイル名を決めて保存します。
保存すると、タイトルの `*` が消えます。

これで最初の計画ができました。
次の章からは、画面の見方と各タブの操作を詳しく説明します。
