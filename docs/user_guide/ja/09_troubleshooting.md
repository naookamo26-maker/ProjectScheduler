# 困ったとき

よくある症状と、その対処をまとめます。
操作を間違えたときは、まず Ctrl+Z（元に戻す）を試してください。

## 日程を組めない

### ガントチャートに「スケジューリングできません」と表示される

計画に必要な入力が足りていません。表示された項目を入力してください。
ガントチャートを表示するには、次のものがそれぞれ1件以上必要です。

| 必要なもの | 入力する場所 |
| --- | --- |
| プロジェクト名、開発開始日 | 基本情報設定タブ |
| チーム、マイルストーン | 基本情報設定タブ |
| タスクを持つワークフロー | ワークフロー設計タブ |
| ジョブ | ジョブ作成タブ |

### 「循環依存が検出されました」と表示される

タスクどうしが、輪になって互いを待っています（A が B を待ち、B が A を待つ、など）。
このままでは、どのタスクも始められません。
メッセージには、輪になっているタスクが「オープニング / 絵コンテ」のように「ジョブ名 / タスク名」で表示されます。

ワークフローの中の依存は、輪になるつなぎ方をしようとした時点で止められるので、原因はたいていジョブどうしの依存です。
表示されたジョブをジョブ作成タブで選び、「依存先ジョブ」で互いに待ち合っているところを確かめて、不要な方を外してください。

### 「配置できる日程が見つかりません」と表示される

タスクを置ける日がありません。例えば、担当チームのライン数が 0 のまま最後まで変わらない、休業日が続いていて作業できる日が無い、といった場合です。
表示されたチームのライン数（変動点を含む）、休業日、タスクの日数を見直してください。

## 日程が思ったとおりにならない

### タスクが思ったより遅く始まる

配置コントロールが既定の 70% になっていると、タスクは締切寄りに置かれます。
もっと早く始める日程を見たいときは、ガントチャートタブの右上の配置コントロールを「最速」寄りに調整してください
（「日程の決まり方」の章の「配置コントロール」）。

ほかに、次のような理由も考えられます。

- 先行タスクがまだ終わっていない（依存）
- 担当チームのラインが、ほかのタスクで埋まっている（ライン数）
- 優先度の高いジョブが先にその時期を取っている（優先度）

### 優先度を上げたのに早くならない

優先度が効くのは、**同じチームのタスクがぶつかったとき**だけです。
先行タスクを待っている、別のチームの作業を待っている、といった理由で遅れているタスクは、優先度を上げても早くなりません。
ガントチャートで、そのタスクの前にある作業を確かめてください。

### ライン数を増やしたのに日程が変わらない

そのチームが混み合っていない、または、遅れの原因が別のところ（依存や、別のチーム）にある可能性があります。
プロジェクト分析タブの「チーム」で、どのチームが「上限に張り付いた日数」や「押し出された件数」が多いかを確かめてください。

### バーの長さが日数より長い

日数は営業日で数えるので、土日・祝日・休業日をまたぐと、バーは日数より長く表示されます。
これは正常です（「日程の決まり方」の章の「日数は営業日で数えます」）。

### 締切に間に合わない

「日程の決まり方」の章の「締切に間に合わないとき」を参照してください。

### 条件を変えたのに、ガントチャートの日程が変わらない

計画を確定している場合、変更は**変更案**として表示されます。状態帯が橙になっていれば、変更は反映されています。
確定の日程として反映するには「変更を確定」を押します（「計画の確定と再計画」の章）。

また、絞り込みで対象のジョブが隠れていないかも確かめてください。

## 表示されない・見当たらない

### タスクやジョブがガントチャートに表示されない

- **絞り込み**で隠れていないかを確かめてください。ガントチャートタブ上部の「絞り込み」を開き、
  各行の「すべて表示」を押し、「ジョブ名で絞り込み」を空にして、「間に合わないジョブのみ表示」をオフにします。
- タスクを**無効**にしていないかを確かめてください。無効にしたタスクはガントチャートに表示されません。
  ジョブ作成タブのタスク上書きで、「有効」にチェックを入れると元に戻ります。

### 「確定する」などのボタンが見当たらない

計画の確定や変更の操作ボタンは、**ガントチャートタブを開いているときだけ**状態帯に表示されます。

### 「選択した変更を確定」が押せない

ガントチャートで、確定していない変更があるタスクを選んでから押してください。
選んだタスクに変更が無いときは押せません。

### 「確定していない計画は全面再計画できません」と表示される

全面再計画は、一度確定した計画を組み直す機能です。まだ確定していない計画は、条件を変えるだけで日程が組み直されます。

## 追加・削除できない

### チームを削除できない

タスクの担当になっているチームは削除できません。
ワークフロー設計タブやジョブ作成タブで、そのチームを担当にしているタスクを別のチームに変えてから削除してください。

### ワークフローを削除できない

ジョブで使われているワークフローは削除できません。
そのワークフローを使うジョブを削除するか、別のワークフローに変えてから削除してください。

### 変動点の行を削除できない

チームのすぐ下の行（開発開始日の行）は、開始時点のライン数なので削除できません。値を変えることはできます。

### 自動で作られたタスク対応を削除できない

依存テンプレートから自動で作られたタスク対応は、個別には削除できません。
不要なときは「有効」のチェックを外してください。
依存そのものが不要なら、「－依存先ジョブ」でジョブどうしの依存を外します。

### 「既に使用されています」と表示される

チーム・マイルストーン・ワークフロー・ジョブの名前は、それぞれ重ならないようにする必要があります。
タスクの名前は、同じワークフローの中で重ならないようにします。別の名前にしてください。

### 依存をつなげない

- 輪になるつなぎ方（A → B → A など）はできません。
- 同じ依存を二重につなぐことはできません。
- 依存テンプレートも、ワークフロー同士が輪になって待ち合う登録はできません。

## ファイルと設定

### 保存したはずの変更が残っていない

入力した内容は、**保存するまでファイルに書き込まれません**。
タイトルのファイル名の前に `*` が付いているときは、保存していない変更があります。Ctrl+S で保存してください。

### 保存できない

保存先のフォルダに書き込めるか（権限）、ディスクの空きが足りているかを確かめてください。
保存に失敗しても、それまでに保存してあったファイルの内容は失われません。
「名前を付けて保存」で、別の場所に保存することもできます。

### 元に戻す（Ctrl+Z）で戻せない

- 別のプロジェクトファイルを開いたり、新しく作ったりすると、それまでの操作の履歴は消えます。
- 操作の履歴が多くなると、古いものから消えます。消えるまでの量は、オプション設定の「Undoに使うメモリの上限」で変えられます。

### 表示言語が切り替わらない

表示言語は、オプション設定で選んだ後、**ツールを起動し直すと**切り替わります。
