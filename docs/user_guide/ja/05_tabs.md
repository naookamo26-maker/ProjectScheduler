# タブごとの操作

この章では、5つのタブで何ができるかを順に説明します。
画面の例には、新作タイトルの制作計画を使います。

どのタブでも、入力した内容はその場で反映されます（ファイルへの保存は別に行います）。
操作を間違えたときは、Ctrl+Z で元に戻せます。

## 基本情報設定

プロジェクト全体に関わる情報をまとめて入力するタブです。
上段にプロジェクト概要、下段に左から「マイルストーン」「チーム」「休業日」が並びます。

<figure>
<img src="images/basic_info_tab.png" alt="基本情報設定タブ">
<figcaption>基本情報設定タブ</figcaption>
</figure>

### プロジェクト概要

プロジェクト名と**開発開始日**を入力します。開発開始日より前には、どの作業も置かれません。

### マイルストーン

締切を登録します。

- 「＋追加」で行を追加し、名前・締切日・備考を入力します。備考はメモ欄で、日程には影響しません。
- 「－削除」で選んだ行を削除します。ジョブやタスクで使われているマイルストーンを削除するときは、確認のメッセージが出ます（削除すると、その割り当ては外れます）。

### チーム

チームと、その**ライン数**（同時に並行して進められる作業の本数）を登録します。
チームは、名前の行と、その下に並ぶ「いつから何本か」の行でできています。

- 「＋チーム」でチームを追加します。名前をダブルクリックして変えます。
- チーム名のすぐ下の行（日付が開発開始日の行）が、開始時点のライン数です。
- 途中でライン数が変わる場合は、チームを選んで「＋変動点」を押し、変わる日と新しいライン数を入力します。
  例えば「エフェクトチームは2027-02-01から2本」のように登録します。
- 「－チーム」で、選んだチームを削除します。タスクで使われているチームは削除できません。
- 「－変動点」で、選んだ変動点を削除します。開始時点の行は削除できません。

ライン数の入れ方は3通りです。

| 入力 | 意味 |
| --- | --- |
| 指定なし | 上限を設けません（新しく作ったチームの既定） |
| 0 | その期間は作業しません |
| 1以上 | その本数まで同時に進めます |

!!! lines-note "ライン数は人数ではありません"
    ライン数は、同時に並行して進められる作業の**本数**です。
    何人いるかではなく、「このチームは同時にいくつの作業を抱えられるか」で決めてください。

### 休業日

土曜・日曜と日本の祝日は、登録しなくても自動で休みとして扱います。
それ以外の休み（年末年始、夏季休業、特定のチームだけの休みなど）をここに登録します。

- 「＋追加」で行を追加し、日付を選びます。
- 「対象チーム」で、全チーム共通か、特定のチームだけの休みかを選びます。
- 「－削除」で選んだ行を削除します。

## ワークフロー設計

作業の流れの型（ワークフロー）を作るタブです。
左側にワークフローの一覧、右側に選んだワークフローの中身が表示されます。

### ワークフローの一覧

- 「＋追加」で新しいワークフローを作ります。
- 「複製」で、選んだワークフローをタスクや依存ごとコピーします。似た流れの型を作るときに便利です。
- 名前をダブルクリックすると、名前を変えられます。
- ドラッグで一覧の並び順を変えられます。
- 「－削除」で削除します。ジョブで使われているワークフローは削除できません。

### ノードビュー

タスクを四角（ノード）、依存を矢印で表す画面です。

<figure>
<img src="images/workflows_tab.png" alt="ワークフロー設計タブのノードビュー">
<figcaption>ノードビュー（ワークフロー「キャラクター制作」）</figcaption>
</figure>

**タスクの操作**

| 操作 | やり方 |
| --- | --- |
| 追加する | 何もないところを右クリック →「タスクを追加」。タスク名・担当チーム・所要日数・先行タスクを入力します |
| 変える | ノードをダブルクリック（または右クリック →「編集」） |
| 削除する | ノードを選んで Delete キー（または右クリック →「削除」） |

タスクを削除すると、その前後の依存は自動でつなぎ直されます。
例えば「A → B → C」の B を削除すると「A → C」になります。

!!! kikan-note "所要日数は「期間」です"
    所要日数は、そのタスクが着手してから仕上がるまでの**期間**（営業日）です。
    工数（人日）ではありません。

**依存の操作**

| 操作 | やり方 |
| --- | --- |
| つなぐ | ノード右端の丸から、次のタスクのノードへドラッグします。タスクの編集画面で「先行タスク」を選んでもつなげます |
| 種類・間隔を変える | 矢印をダブルクリックします |
| 削除する | 矢印を選んで Delete キー |

依存が輪になる（A → B → A のように、いつまでも始められない）つなぎ方をしようとすると、エラーになってつながりません。

矢印をダブルクリックすると、依存の種類と間隔を変えられます。

| 設定 | 意味 |
| --- | --- |
| 完了 → 開始（既定） | 先行タスクが終わってから、後続タスクを始めます |
| 開始 → 開始 | 先行タスクが始まったら、後続タスクも始められます |
| ラグ | 間に空ける営業日数です。マイナスにすると、その日数だけ早く始められます |

既定以外の設定をした矢印には、「FS+2」「SS+1」のような印が付きます
（FS は完了 → 開始、SS は開始 → 開始、数字はラグです）。

**そのほか**

- 上部の「最短◯日」は、依存だけで決まる最短の期間です。チームの混み具合は考えていないので、実際の日程はこれより長くなることがあります。
- `A` キーで全体を表示し、`F` キーで選んだノードに合わせて拡大します。
- ノードはドラッグで動かせますが、見やすくするための一時的なものです。タスクを追加・変更すると、自動で並べ直されます。

### テーブルビュー

同じ内容を表で見られます。上流のタスクほど上に並びます。
「＋追加」「編集」「－削除」は、ノードビューと同じ画面で行います。

### 依存テンプレート

別のワークフローの作業を待つ関係を、**ワークフローの組み合わせごとに**決めておく機能です。

例えば「カットシーン制作」の「モーション収録」は、登場するキャラクターの「モデル制作」が終わるまで始められません。
このルールを依存テンプレートとして一度登録しておけば、ジョブ作成タブで
「オープニング（カットシーン）は主人公（キャラクター）を待つ」と指定するだけで、
「主人公のモデル制作 → オープニングのモーション収録」という依存が自動で作られます。

<figure>
<img src="images/workflows_cutscene.png" alt="依存テンプレートが表示されたノードビュー">
<figcaption>「カットシーン制作」の依存テンプレート（上段のピンクの枠）</figcaption>
</figure>

- ノードビューの何もないところを右クリック →「依存テンプレートを追加」で登録します。
  テーブルビューの下の表からも登録できます。
- 登録では、「このワークフローのどのタスク」が「どのワークフローのどのタスク」を待つかを選びます。
- ノードビューでは、ピンクの破線の枠と点線の矢印で表示されます。
- ワークフロー同士が輪になって待ち合う登録はできません。

## ジョブ作成

実際の仕事（ジョブ）を作り、ジョブごとの調整やジョブ同士の依存を設定するタブです。
左側にジョブの一覧、右側に選んだジョブの「タスク上書き」と「依存先ジョブ」が表示されます。

<figure>
<img src="images/jobs_opening.png" alt="ジョブ作成タブ">
<figcaption>ジョブ作成タブ（「オープニング」を選んだところ）</figcaption>
</figure>

### ジョブの一覧

- 「＋追加」でジョブを追加します。
- 「複製」で、選んだジョブを、タスク上書きや依存先ジョブごとコピーします。
- 「－削除」で削除します。ほかのジョブから待たれているジョブを削除するときは、確認のメッセージが出ます。
- 列の見出しをクリックすると、その列で並べ替えます。

| 列 | 内容 |
| --- | --- |
| ジョブ名 | ダブルクリックして入力します |
| ワークフロー | どの型から作るかを選びます |
| 既定マイルストーン | このジョブをどの締切までに終えるかを選びます |
| 優先度 | 数値が小さいほど優先されます。0 にすると「（未指定）」になり、最も後回しになります |
| タグ | 絞り込みに使う自由な目印です。複数付けるときはカンマで区切ります（例: メイン, 体験版） |

### 絞り込み

上部の「絞り込み」を開くと、ワークフロー・マイルストーン・タグで、一覧に出すジョブを絞り込めます。
チェックを外した項目のジョブが一覧から隠れるだけで、データは消えません。

### タスク上書き

選んだジョブの各タスクを、このジョブだけ型から変えたいときに使います。
変えていない項目には、「既定（10日）」「（既定: プランナー）」のように型の値が表示されます。

| 列 | 内容 |
| --- | --- |
| 有効 | チェックを外すと、このジョブではそのタスクを行いません。前後の依存は自動でつなぎ直されます |
| 日数 | このジョブだけ日数を変えます |
| マイルストーン | このタスクだけ別の締切に合わせます |
| チーム | このタスクだけ別のチームが受け持ちます |
| 開始固定日 | このタスクを始める日を固定します（下記） |
| 状態 | 未着手・進行中・完了を記録します（下記） |
| タグ | このタスクだけに付ける目印です |

!!! kikan-note "日数の上書きも「期間」です"
    日数を変えるときも、「このジョブではどれくらいの期間で仕上がるか」で決めてください。
    担当する人を増やしたから日数を半分にする、という考え方はしません。

**マイルストーン**は、先行タスクより早い締切は選べません。
また、先行タスクの締切を遅らせると、後続タスクの締切も自動で合わせて遅くなります（そのときはメッセージで知らせます）。

**開始固定日**は、「この日に始めると決まっている」タスクに使います。
例えば、外部の収録スタジオの予約日や、実際に作業を始めた日です。
依存やライン数と矛盾する日付でも入力できます。矛盾はガントチャートで知らせます（オレンジの破線の枠）。
Delete キーで固定を外せます。

**状態**は、実際の進み具合を記録する欄です。日付から自動で判断されることはありません。
状態を変えても、それだけで日程は変わりません（計画を確定した後の扱いは「計画の確定と再計画」の章で説明します）。
記録した状態は、プロジェクト分析タブで集計されます。

### 依存先ジョブ

選んだジョブが、ほかのどのジョブを待つかを設定します。

- 「＋依存先ジョブ」で、待つジョブを選びます。複数まとめて選べます。
- 依存テンプレートが登録されていれば、どのタスクがどのタスクを待つか（**タスク対応**）が自動で作られます。
  ジョブ名の左の ▸ を開くと確認できます。上の画面では、オープニングが主人公と始まりの村を待ち、
  「モデル制作 → モーション収録」「背景モデル → 編集・仕上げ」のタスク対応が自動で作られています。
- 自動で作られたタスク対応が不要なときは、「有効」のチェックを外します。
- テンプレートで表せない例外的な依存は、「＋タスク対応」で個別に追加します（種別が「手動」になります）。
- 「－依存先ジョブ」で、待つジョブを外します。自動で作られたタスク対応も一緒に外れます。

ジョブ同士の依存が輪になっていると、ガントチャートでエラーとして知らせます。

## ガントチャート

ツールが組み立てた日程を表示するタブです。
タブを開くたびに、最新の入力で日程が組み直されます。

### 見方

左端にジョブが並び、各タスクが横長の四角（**バー**）で表示されます。
バーの左端が開始日、右端が終了日、色が担当チームです。
名前の左の小さな色は、どのワークフローのジョブかを表します。
1つのジョブの中で段が分かれている部分は、同時に進むタスクです。

バーの見た目は、タスクの状況によって変わります。

入力が足りない（チームが無い、ジョブが無いなど）ときや、依存が輪になっているときは、
日程を組めない理由が上部に赤字で表示されます。

### 表示の操作

| 操作 | やり方 |
| --- | --- |
| 拡大・縮小 | マウスホイール（Ctrl を押しながらで横だけ、Shift を押しながらで縦だけ） |
| 表示位置を動かす | マウスの中ボタン（ホイール）を押したままドラッグ |
| 全体を表示 | `A` キー |
| 選んだタスクに合わせて拡大 | `F` キー |

### 絞り込み

上部の「絞り込み」を開くと、表示するジョブを絞り込めます。

- ワークフロー・チーム・タグで絞り込めます。
- 「ジョブ名で絞り込み」に文字を入れると、名前にその文字を含むジョブだけを表示します。
- 「間に合わないジョブのみ表示」をオンにすると、締切に間に合わないタスクを持つジョブだけを表示します。

絞り込みは表示を変えるだけで、日程は変わりません。

### 配置コントロール

右上の「配置コントロール」で、タスクを「最速」（できるだけ早く）から「ギリギリ」（締切に近く）までのどこに置くかを調整します。
詳しくは「日程の決まり方」の章で説明します。

### タスクを調整する

ガントチャートを見ながら、タスクの開始日や日数を変えられます。
変えた内容は、ジョブ作成タブの「タスク上書き」に書き込まれ、日程が組み直されます。

**1. タスクを選ぶ**

バーをクリックすると選ばれ、枠が点線になります。
Ctrl を押しながらクリックすると追加で選べます。
何もないところからドラッグすると範囲で選べ、左端のジョブ名をクリックするとそのジョブのタスクをすべて選べます。

**2. ドラッグで動かす**

**Shift を押しながら**バーをドラッグします（押すキーはオプションで変えられます。Shift を押していないと動きません）。

- バーの中ほどをつかんで左右に動かすと、**開始日**が変わります。選んでいるタスクがすべて同じ営業日数だけ動き、開始固定日として記録されます。
- バーの右端をつかんで伸び縮みさせると、**日数**が変わります。

ドラッグしているあいだは、動かした先に半透明の影が表示されます。
ボタンを離すと、その位置で日程が組み直されます。

開始固定日・日数・チーム・マイルストーン・状態・有効・タグを入力できます。
「今の開始日で固定」を押すと、いま計算されている開始日でそのタスクを固定します。

</figure>

編集ウィンドウは開いたままにしておけます。ガントチャートで別のバーを選ぶと、その内容に切り替わります。
複数のタスクを選んでいるときは、開始日を「◯営業日ずらす」、チームや状態をまとめて変える、といった操作ができます。

**右クリックのメニュー**からも、開始日の固定・解除、状態、チームの変更、タスクを無効にする、といった操作ができます。
無効にしたタスクはガントチャートに表示されなくなります。有効に戻すときは、ジョブ作成タブのタスク上書きで「有効」にチェックを入れます。

!!! kikan-note "バーの長さは「期間」です"
    バーの右端を伸ばすことは、そのタスクの**期間を延ばす**ことです。
    作業量（工数）を増やすという意味ではありません。

### ガントチャートをファイルに書き出す

「ファイル」→「ガントチャートを生成」を選び、書き出し先のフォルダを選ぶと、
ガントチャートを HTML ファイル（`schedule_gantt.html`）として書き出します。
ブラウザで開いて見られます。

## プロジェクト分析

ガントチャートタブと同じ日程を、数字とグラフで要約するタブです。
このタブで入力するものはありません。

<img src="images/analysis_tab.png" alt="プロジェクト分析タブ">
<figcaption>プロジェクト分析タブ（マイルストーン）</figcaption>
</figure>

### 上段の6つの数字

| 項目 | 内容 |
| --- | --- |
| 規模 | ジョブとタスクの件数 |
| 計画期間 | 最初のタスクの開始から最後のタスクの終了まで。最後のマイルストーンまでの余裕も表示します |
| タスクの状態 | ジョブ作成タブで記録した状態（完了・進行中・未着手）の件数 |
| 同時タスク数のピーク | 全チームで同時に進むタスクが最も多いときの本数と、その時期 |
| 締切に間に合わないタスク | 件数、対象のジョブの数、最大の遅れ日数（0件でなければ赤字） |
| 開始固定日の違反 | 開始固定日どおりに置けないタスクの件数 |

!!! lines-note "数えているのは件数と本数です"
    このタブの数字は、タスクの**件数**と、同時に進むタスクの**本数**です。
    工数（人日）や人数は集計しません。

### マイルストーン

マイルストーンごとの状況を表にします。

| 列 | 内容 |
| --- | --- |
| 進捗 | そのマイルストーンまでに割り当てられたタスクが、全体の何％にあたるか（累計）。計画上の割合で、作業の完了とは関係ありません |
| 締切日 | マイルストーンの締切 |
| 最終終了日 | そのマイルストーンのタスクが最も遅く終わる日 |
| スラック | 締切までの余裕の日数。マイナス（赤字）は締切を過ぎていることを表します |
| 超過 | 締切に間に合わないタスクの件数 |
| ジョブ・タスク | 対象のジョブとタスクの件数 |
| 完了・進行中・未着手 | 記録した状態ごとのタスクの件数 |

「内訳」で「チーム別」「ワークフロー別」を選ぶと、1つのチームやワークフローに絞った数字に切り替わります。

### チーム

チームごとの混み具合を見ます。

<figure>
<img src="images/analysis_team.png" alt="プロジェクト分析タブのチーム">
<figcaption>チームごとの同時タスク数の推移</figcaption>
</figure>

グラフは、各チームが同時に抱えるタスクの本数を週ごとに積み上げたものです。
表の行を選ぶと、そのチームだけのグラフに切り替わります。

| 列 | 内容 |
| --- | --- |
| ピーク・ピーク時期 | 同時に抱えるタスクが最も多いときの本数と時期 |
| 上限に張り付いた日数 | ライン数いっぱいまで作業を抱えていた日数（ライン数が「指定なし」のチームは空欄） |
| タスク件数 | そのチームが受け持つタスクの件数 |
| 押し出された件数 | ライン数が足りずに、本来置けた日より後ろにずれたタスクの件数 |
| 超過件数 | 締切に間に合わないタスクの件数 |

「上限に張り付いた日数」や「押し出された件数」が多いチームは、計画のボトルネックになっている可能性があります。
ライン数を「指定なし」にしておくと、そのチームが**何本並行できれば計画どおりに進むか**を、ピークの本数から読み取れます。

### ワークフロー

ワークフローごとに、ジョブの件数、1つのジョブにかかる期間（中央値）、締切に間に合わないタスクの件数を表示します。
グラフには、その時期に進んでいるタスクの件数をワークフローごとに積み上げて表示します。
