# 付録

## A. 元に戻す・やり直す

入力・削除・並べ替え・ガントチャートでの調整・計画の確定など、画面での編集はすべて元に戻せます。

| 操作 | メニュー | ショートカット |
| --- | --- | --- |
| 元に戻す | 編集 → 元に戻す | Ctrl+Z |
| やり直す（元に戻した操作をもう一度行う） | 編集 → やり直す | Ctrl+Y |

- 1回の操作は、まとめて1回で元に戻ります（複数のタスクをまとめて削除した場合なども1回）。
- 元に戻すと、その操作をしたときに開いていたタブや、選んでいた行・タスクも一緒に戻ります。
- 別のプロジェクトファイルを開いたり、新しく作ったりすると、それまでの履歴は消えます。
- 履歴が多くなると、古いものから消えます。履歴に使うメモリの量は、オプション設定の「Undoに使うメモリの上限」で変えられます。
- オプション設定の変更は、プロジェクトの内容ではないので、元に戻す対象になりません。

## B. 操作の一覧

### キーボード

| 操作 | キー |
| --- | --- |
| 上書き保存 | Ctrl+S |
| 名前を付けて保存 | Ctrl+Shift+S |
| 元に戻す | Ctrl+Z |
| やり直す | Ctrl+Y |

### ワークフロー設計（ノードビュー）

| 操作 | やり方 |
| --- | --- |
| タスクを追加する | 何もないところを右クリック →「タスクを追加」 |
| 依存テンプレートを追加する | 何もないところを右クリック →「依存テンプレートを追加」 |
| タスク・依存テンプレートを変える | ダブルクリック（または右クリック →「編集」） |
| 依存をつなぐ | ノード右端の丸から、次のノードへドラッグ |
| 依存の種類・ラグを変える | 矢印をダブルクリック |
| 選んだものを削除する | Delete キー（または右クリック →「削除」） |
| 範囲で選ぶ | 何もないところからドラッグ |
| 拡大・縮小 | マウスホイール |
| 表示位置を動かす | マウスの中ボタン（ホイール）を押したままドラッグ |
| 全体を表示 | `A` キー |
| 選んだノードに合わせて拡大 | `F` キー |

### ガントチャート

| 操作 | やり方 |
| --- | --- |
| タスクを選ぶ | クリック（Ctrl を押しながらで追加） |
| 範囲で選ぶ | 何もないところからドラッグ |
| ジョブのタスクをすべて選ぶ | 左端のジョブ名をクリック |
| 開始日を動かす | Shift を押しながらバーをドラッグ（キーはオプションで変えられます） |
| 日数を変える | Shift を押しながらバーの右端をドラッグ |
| 編集ウィンドウを開く | バーをダブルクリック（または右クリック →「編集」） |
| 開始日の固定・解除、状態、チーム、無効にする | 右クリック |
| 拡大・縮小 | マウスホイール（Ctrl を押しながらで横だけ、Shift を押しながらで縦だけ） |
| 表示位置を動かす | マウスの中ボタン（ホイール）を押したままドラッグ |
| 全体を表示 | `A` キー |
| 選んだタスクに合わせて拡大 | `F` キー |

### 表の入力欄

| 操作 | やり方 |
| --- | --- |
| 開始固定日を外す | 開始固定日の欄で Delete キー |
| 名前を変える（チーム・ワークフローなど） | 名前をダブルクリック |
| 並べ替える（ジョブの一覧など） | 列の見出しをクリック（もう一度押すと逆順） |

## C. 用語集

このガイドに出てくる言葉の意味をまとめます。

### 計画の組み立て

| 言葉 | 意味 |
| --- | --- |
| プロジェクト | 計画全体の単位。1つのプロジェクトを1つのファイル（`.pschedule`）に保存します |
| 開発開始日 | プロジェクトの開始日。これより前には作業を置きません |
| マイルストーン | 締切。名前と締切日を持ちます |
| チーム | 作業を受け持つ単位。部署・個人・協力会社など、自由に決められます |
| ライン数 | チームが同時に並行して進められる作業の本数。人数ではありません |
| 変動点 | チームのライン数が途中で変わる日 |
| 休業日 | 作業をしない日。土日・祝日は登録しなくても休みとして扱います |
| 営業日 | 作業をする日。日数は営業日で数えます |
| ワークフロー | 作業の流れの型。繰り返し現れる仕事の進め方を1回だけ作っておきます |
| タスク | ワークフローの中の1つの作業。担当チームと日数（期間）を持ちます |
| 日数（所要日数） | タスクが着手してから仕上がるまでの期間（営業日）。工数ではありません |
| 依存 | タスクの前後関係。先に終わるべきタスクが**先行タスク**、その後に始めるタスクが**後続タスク**です |
| ラグ | 依存の間に空ける営業日数。マイナスにすると、その分だけ早く始められます |
| 依存テンプレート | ワークフローの組み合わせごとに決めておく、「どのタスクがどのタスクを待つか」のルール |
| ジョブ | ワークフローの型から作る実際の仕事 |
| 優先度 | 作業がぶつかったときの順番。数値が小さいほど先になります |
| タグ | ジョブやタスクに付ける自由な目印。絞り込みに使います |
| タスク上書き | ジョブごとに、型から日数・チーム・締切などを変える設定 |
| 有効・無効 | そのジョブでタスクを行うかどうか。無効にしたタスクは日程に入りません |
| 開始固定日 | 始める日が決まっているタスクの開始日。ほかの決まりより優先してその日に置きます |
| 状態 | タスクの進み具合の記録（未着手・進行中・完了） |
| 依存先ジョブ | そのジョブが待つ、ほかのジョブ |
| タスク対応 | 依存先ジョブのどのタスクを、このジョブのどのタスクが待つかの組み合わせ |

### 日程と計画の状態

| 言葉 | 意味 |
| --- | --- |
| 期間 | 着手から完了までにかかる日数。このツールが扱う日数は、すべて期間です |
| 工数 | 作業にかかる手間の量（人日などで数えるもの）。このツールでは扱いません |
| ガントチャート | 日程を横長の四角（バー）で表した図 |
| 配置 | タスクを「最速」から「ギリギリ」までのどこを基準に置くかの設定 |
| 締切超過 | タスクがマイルストーンの締切に間に合わないこと |
| 状態帯 | 画面上部の帯。計画が未確定・確定済み・変更案のどれかを示します |
| 確定 | 合意した日程を保存すること。確定した日程は、変更を確定するまで変わりません |
| 変更案 | 確定の後に、日程に関わる変更を当てはめた、まだ合意していない日程 |
| 全面再計画 | 未着手のタスクを、基準日以降に全体として組み直すこと |
| 基準日 | 全面再計画で、新しい計画が始まる日 |
| 未確定に戻す | 確定をやめて、確定する前と同じように日程を組み直せる状態に戻すこと |
