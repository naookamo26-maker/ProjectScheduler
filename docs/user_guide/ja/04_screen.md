## メニュー

| メニュー | 項目 |
| --- | --- |
| ファイル | 新規プロジェクト、プロジェクトを開く、保存、名前を付けて保存、ガントチャートを生成、終了 |
| 編集 | 元に戻す、やり直す、オプション |
| ヘルプ | バージョン情報 |

ファイルの操作、元に戻す／やり直す、バージョン情報は「起動と初期設定」の章で、
「ガントチャートを生成」は「タブごとの操作」の章のガントチャートの節で説明します。

## 計画の状態帯

どのタブを開いていても、タブの上に1本の帯が表示されます。
帯の色と文字で、計画がいまどの状態にあるかが分かります。

| 状態 | 帯の色 | 意味 |
| --- | --- | --- |
| 未確定 | 灰色 | 計画を試している段階です。条件を変えると日程が自由に組み直されます |
| 確定済み | 緑 | 関係者と合意した日程が保存されています |
| 変更案 | 橙 | 確定した計画に対して、変更を試している最中です |

確定と変更案の使い方は「計画の確定と再計画」の章で説明します。
計画を作り始めたばかりのうちは「未確定」のままで構いません。

## タブ

5つのタブは、**左の3つが入力、右の2つが結果**という並びになっています。
左から順に入力していくと、計画が組み上がります。

| タブ | 役割 | 内容 |
| --- | --- | --- |
| 基本情報設定 | 入力 | プロジェクト名と開発開始日、マイルストーン、チームとライン数、休業日 |
| ワークフロー設計 | 入力 | 作業の流れの型（タスクと依存） |
| ジョブ作成 | 入力 | 実際の仕事、優先度、ジョブごとの調整、ジョブ同士の依存 |
| ガントチャート | 結果 | ツールが組み立てた日程。日程を見ながらタスクを調整することもできます |
| プロジェクト分析 | 結果 | 計画全体の要約（締切に間に合わない件数、チームの混み具合など） |

入力のタブで条件を変えてから結果のタブを開くと、日程は自動で組み直されます。
計算しているあいだは、ガントチャートの上部に「スケジューリングを計算中です...」と表示されます。計算中も画面は操作できます。

## ステータスバーとタイトル

画面の一番下のステータスバーには、開いているファイルの場所が表示されます。
ウィンドウのタイトルにはファイル名が表示され、保存していない変更があると先頭に `*` が付きます。
